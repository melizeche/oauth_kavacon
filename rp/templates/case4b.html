El provider firma con RS256. La falla es del cliente: cómo verifica el id_token.

Cómo verifica este RP

{% if variant == 'insecure' %} 
# elige el algoritmo segun el header del token (MAL)
alg = header["alg"]
if alg == "RS256": verificar con la clave publica (RSA)
if alg == "HS256": usar la clave PUBLICA del JWKS como secreto HMAC  # ← el bug

Si el token dice HS256, el RP usa la clave pública (que es conocida, está en el JWKS) como secreto HMAC. El atacante firma con esa misma clave pública y pasa la verificación.

{% else %} 
# algorithm fijo, nunca se confia en el header (BIEN)
jwt.decode(token, clave_publica, algorithms=["RS256"])

Solo se acepta RS256. Un token HS256 se rechaza sin importar lo que diga el header.

{% endif %}
